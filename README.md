# Anesthesia Boards Navigator

An unofficial study guide for anesthesiology residents, built on the American Board of Anesthesiology's Initial Certification Content Outline (BASIC and ADVANCED).

**Open the guide:** https://tjsmith41.github.io/boards-guide/

- Every topic in the outline, with a page for each section, topic and subtopic, plus search (words or outline codes like II.C.2).
- A private My notes box on every topic. Notes stay in each resident's own browser, and the My notes page backs them up and restores them.
- Study notes written for the guide appear as each topic is finished.
- A Feedback button on every page sends a comment to the guide's author through a Google Form. It's anonymous unless the resident adds a name.

The whole site is the single file `index.html`, which is generated.

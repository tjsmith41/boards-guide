# Anesthesia Boards Navigator

An unofficial study guide for anesthesiology residents, built on the American Board of Anesthesiology's Initial Certification Content Outline (BASIC and ADVANCED).

**Open the guide:** https://tjsmith41.github.io/boards-guide/

**Made by AI.** Everything here should be independently verified.

- Every topic in the outline, with a page for each section, topic and subtopic, plus search (words or outline codes like II.C.2).
- A private My notes box on every topic. Notes stay in each resident's own browser, and the My notes page backs them up and restores them.
- Study notes written for the guide appear as each topic is finished.
- A Rotation picker in the menu narrows the topic list and search to one rotation on the residency schedule. Each rotation has a page with the outline sections it covers and the related topics their notes link to most.
- A Review button lists the points still open from the November 2026 review of every note against Miller's Anesthesia (10th edition) and current guidelines: open questions, errors not fixed yet, book vs current differences, points that could say more, wording, and the parts the review didn't check. A topic with open points shows them in a closed Under review box at the top of its page. Every point has a Send info button, so a resident who knows the answer or has a source can send it for that point.
- A Feedback button on every page sends a comment through a Google Form. It's anonymous unless the resident adds a name. Send info goes the same way, tagged with the review point.

The whole site is the single file `index.html`, which is generated.
